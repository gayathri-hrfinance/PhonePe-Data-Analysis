PhonePe Data Analysis Dashboard
Project Overview
This is a beginner-level data analysis project built using Python and Streamlit. It explores transaction and user engagement data from PhonePe, focusing on trends across states, districts, and pincodes. The goal is to learn how to work with JSON data, perform SQL queries, and build interactive dashboards.

Data Source
JSON files collected from   https://github.com/PhonePe/pulse
Data includes transactions, users, and insurance metrics across different regions
Tools & Technologies Used 
Python
Pandas
SQLite3
Streamlit
Plotly
JSON
GitHub
Project Structure
The data was organized into 9 tables by considering the data inside the State folders

Aggregate_Transaction, Aggregate_User, Aggregate_Insurance
Map_Transaction, Map_User, Map_Insurance
Top_Transaction, Top_User, Top_Insurance
Each file was processed, converted to CSV, and then stored in SQL tables for analysis.
